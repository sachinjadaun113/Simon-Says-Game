# Simon-Says-Game
This is a web-based Simon Says game built using HTML, CSS, and JavaScript. It’s a digital version of the classic memory game where the player must follow and repeat an ever-growing sequence of colors .
The game interface displays four colored buttons (red, green, yellow, and blue). The computer generates a random sequence of button flashes, and the player must repeat the sequence correctly to advance to the next level. With each successful level, the sequence becomes longer, increasing the difficulty.
🛠️ Technologies Used:
HTML: For the basic structure of the game

CSS: For styling the layout, colors, animations, and responsive design

JavaScript: For all the game logic, including:

> Generating random sequences

> Handling user input and clicks

> Comparing player input to the correct sequence

> Managing game state (start, level up, game over)
